# 🚀 Gen-Z Trends (Full Stack E-Commerce Project)

## 📌 Overview
Gen-Z Trends is a full-stack web application built using React and Node.js that simulates a modern e-commerce and trends discovery platform. It allows users to browse products, view recommendations, and interact with backend APIs in a structured and scalable architecture.

This project is created for internship submission and demonstrates full-stack development skills with clean and modular code structure.

---

## 🧠 Objective
- Build a full-stack application using React + Node.js
- Demonstrate REST API creation and integration
- Implement modular frontend architecture
- Show clean separation between client and server

---

- React.js

### 1. Clone Repository

### 3. Run Backend
cd server  
npm install
